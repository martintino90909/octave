# Guitar samples

Steel-string acoustic guitar notes, MIDI 40 (E2) to 84 (C6), one file per note,
named by MIDI number. Octave's demos are mixed from these.

From the FluidR3 GM soundfont (by Frank Wen, MIT licence), as rendered to MP3 in
gleitz/midi-js-soundfonts (MIT licence, Copyright (C) 2012 Benjamin Gleitzman):
https://github.com/gleitz/midi-js-soundfonts
